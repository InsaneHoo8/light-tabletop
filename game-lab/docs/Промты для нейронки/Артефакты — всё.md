# Артефакты: полный справочник

Этот документ описывает все артефакты игры «Война за Сосиску» и правила обращения с ними. Он самодостаточен: по нему можно судить о карте, не имея перед глазами остальных материалов.

## Что такое артефакт

Артефакт — карта, которую берут из общей колоды и применяют в свой ход отдельным действием. Применение артефакта не заменяет обычную атаку и не считается применением способности.

Колода состоит из двадцати четырёх карт: по шесть на каждый из четырёх миров. Когда колода заканчивается, сброс перемешивается и образует новую.

## Свой и чужой мир

Артефакт своего мира бесплатен. Артефакт чужого мира требует оплаты менталкой по своей цене.

## Обмен

Обычную карту можно сбросить ради энергии в размере обмена. Это быстрое действие: оно не тратит ход, и сразу после него игрок делает своё основное действие.

Карту, которая сама восстанавливает энергию или здоровье, обменивают на здоровье. Такой обмен остаётся полноценным действием и тратит ход.

Сброс двух артефактов позволяет пополнить руку способностей: взять карту из своего сброса способностей или верхнюю карту личного пула, соблюдая лимит руки.
