# Пул способностей
Всего пятьдесят две карт. В основном правиле способности личные; пул используется в экспериментальном режиме драфта.
## Фэнтези
- **Боевой крик** — две энергии, сыграна сто пятьдесят два раз — провоцирует соседа: тот получает обычный удар, бьёт в ответ на две меньше и пропускает ход
- **Яростный удар** — две энергии, сыграна триста сорок два раз — три урона всем остальным и два себе
- **Ядовитый удар** — две энергии, сыграна триста пятьдесят шесть раз — шесть урона выбранной цели
- **Ловушка-аура** — две энергии, сыграна ноль раз — до вашего следующего хода первый, кто нанесёт вам урон, получает столько же и сам не ранит вас
- **Театральный выпад** — две энергии, сыграна триста три раз — четыре урона цели и сброс одной её способности
- **Карманник** — одна энергии, сыграна сто семьдесят два раз — крадёт у цели два артефакта и две менталки
- **Вспышка Бездны** — две энергии, сыграна двести двадцать семь раз — шесть урона цели и два себе
- **Хаотическое заклинание** — две энергии, сыграна триста пятьдесят один раз — на выбор: три урона всем, пять здоровья себе или три энергии себе
- **Призыв Иллюзий** — одна энергии, сыграна два раз — щит на три урона
- **Разрыв реальности** — три энергии, сыграна триста семьдесят шесть раз — четыре урона всем остальным
- **Мутация** — три энергии, сыграна ноль раз — семь урона цели и три себе
- **Научный прорыв** — две энергии, сыграна сто сорок два раз — щит на три и две энергии себе
- **Порча** — три энергии, сыграна ноль раз — цель теряет две способности
## Киберпанк
- **Овердрайв** — две энергии, сыграна ноль раз — плюс два к урону
- **Система самовосстановления** — три энергии, сыграна двести тридцать два раз — восстанавливает три здоровья
- **Контракт** — две энергии, сыграна ноль раз — крадёт у цели два артефакта и сбрасывает одну её способность
- **Инвестиция** — одна энергии, сыграна триста пятнадцать раз — обменивает артефакт на три здоровья и три менталки
- **Подставной счёт** — две энергии, сыграна триста семьдесят два раз — крадёт по одному артефакту у всех игроков и наносит всем по одному урону
- **Скупка долгов** — три энергии, сыграна триста сорок шесть раз — ворует у цели три здоровья и три энергии
- **Цифровой аукцион** — три энергии, сыграна ноль раз — четыре урона цели и кража одного артефакта
- **Перепрошивка** — две энергии, сыграна двести пятьдесят шесть раз — цель пропускает ход и теряет один артефакт и одну способность
- **Цифровой паразит** — две энергии, сыграна триста восемьдесят пять раз — выбранный игрок бьёт того, кого укажете, и пропускает свой следующий ход
- **Взлом** — две энергии, сыграна двести сорок один раз — крадёт у цели один артефакт, одно здоровье и две менталки
- **Рекурсия** — три энергии, сыграна ноль раз — пять урона цели
## Космос
- **Поглощение данных** — одна энергии, сыграна ноль раз — забирает две энергии у цели
- **Перепрограммирование материи** — две энергии, сыграна ноль раз — восстанавливает два здоровья и одну энергию
- **Резервная копия** — две энергии, сыграна триста двадцать три раз — щит на пять урона
- **Анализ слабости** — три энергии, сыграна сто шестьдесят один раз — пять урона цели, пробивает щит
- **Перегрузка системы** — три энергии, сыграна триста восемьдесят четыре раз — всем остальным: один урон, минус три энергии и минус две менталки
- **Психический всплеск** — две энергии, сыграна шестьдесят семь раз — три урона менталке цели и два урона здоровью
- **Иллюзия боли** — три энергии, сыграна семьдесят четыре раз — цель пропускает ход и получает два урона
- **Ментальный клинок** — две энергии, сыграна двести пятьдесят четыре раз — пять урона здоровью цели
- **Волна ужаса** — три энергии, сыграна триста двадцать пять раз — два урона всем остальным и минус одна энергия у каждого
- **Вторжение в разум** — две энергии, сыграна четыре раз — цель пропускает ход
- **Психическая броня** — две энергии, сыграна ноль раз — щит на четыре урона
- **Пожирание мысли** — три энергии, сыграна триста тридцать один раз — четыре урона цели, три здоровья себе и кража двух способностей
- **Орбитальный залп** — три энергии, сыграна триста семьдесят шесть раз — пять урона цели
- **Перенаправление щитов** — две энергии, сыграна один раз — блокирует три урона
## Земля 404
- **Магический тост** — одна энергии, сыграна двести пятьдесят раз — восстанавливает три здоровья и одну менталку
- **Опьянённый удар** — одна энергии, сыграна двести пятьдесят два раз — четыре урона цели и один себе
- **Пьяный шаффл** — две энергии, сыграна четыреста девять раз — на выбор: пять урона цели, четыре здоровья себе, два урона всем или три энергии себе
- **Опохмел** — одна энергии, сыграна двести девяносто один раз — три здоровья и две менталки себе
- **Бутылка в голову** — три энергии, сыграна ноль раз — шесть урона цели и два себе
- **Вирусный пост** — одна энергии, сыграна двести девяносто раз — два урона всем остальным
- **Коллаборация** — одна энергии, сыграна ноль раз — вы и выбранный игрок получаете по две менталки
- **Лайк за кровь** — две энергии, сыграна двести сорок один раз — один урон всем остальным и лечение по одному за каждого
- **Стрим-снайпер** — три энергии, сыграна сто девяносто один раз — четыре урона цели и минус две менталки у неё
- **Хайп-волна** — две энергии, сыграна триста девяносто восемь раз — на выбор: три урона всем, шесть здоровья себе и три всем, или все теряют три энергии
- **Указ №∞** — две энергии, сыграна двести пятьдесят пять раз — вы получаете ещё один ход: можно ударить дважды или ударить и применить способность
- **Великая речь** — одна энергии, сыграна триста сорок два раз — три менталки себе и один урон всем остальным
- **Единый день голосования** — три энергии, сыграна сто пятьдесят четыре раз — все игроки не могут наносить урон обычной атакой на своём ходу
- **Народная любовь** — три энергии, сыграна семьдесят один раз — два здоровья и две менталки себе, все остальные получают один урон
