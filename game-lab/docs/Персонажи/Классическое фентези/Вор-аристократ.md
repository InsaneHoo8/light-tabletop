# Вор-Аристократ «Жюльен»

Жюльен — циничный дворянин без гроша в кармане, променявший фамильный замок на карманные кражи и дуэли на задворках летающих островов. В бою он делает ставку на скорость, яды, обман и воровство чужих запасов.

**Здоровье двадцать пять единиц, урон обычной атаки три единицы, менталка пять единиц, энергия пять единиц. Лимит руки четыре способности. Ёмкость щита пять единиц.**

**Пассивка. Обычной атакой может украсть один артефакт вместо удара.**

## Способности

**Пункт один. Ловкость рук — одна единица энергии. Крадёт 1 артефакт. Нужна цель.**

**Пункт два. Удар исподтишка — три единицы энергии. Пробивает щит на 4, срезает 2 щита, а без щита наносит 6 урона. Нужна цель.**

**Пункт три. Парирование рапирой — одна единица энергии. Реакция: полностью отменяет входящий удар и возвращает весь урон нападающему.**

**Пункт четыре. Дымовая шашка — две единицы энергии. Снимает негативные эффекты и пропуски, даёт 1 дополнительное действие.**

**Пункт пять. Отравленная игла — две единицы энергии. Наносит 2 урона выбранной цели, вешает 3 отложенного урона до конца хода цели. Нужна цель.**

**Пункт шесть. Подмена карманов — одна единица энергии. Отдаёт свой артефакт, крадёт 2 артефакта. Нужна цель.**

**Пункт семь. Выстрел из лука — четыре единицы энергии. Наносит 8 урона выбранной цели. Нужна цель.**

**Пункт восемь. Благородный грабеж — три единицы энергии. Наносит 3 урона выбранной цели, забирает 3 единицы здоровья у цели и восстанавливает столько же себе, отнимает 3 единицы менталки, отнимает 3 единицы энергии, даёт 3 единицы менталки, даёт 3 единицы энергии. Нужна цель.**
