# Документы игры: один источник

Здесь лежат **исходники всех документов игры** в формате markdown. Это единственное место, где текст правится руками.

Папка на компьютере «Лайтовая настолка» — копия. Файлы docx в ней собираются отсюда автоматически, ничего вручную там править не нужно.

## Как устроено

- Путь повторяет папку игры. `Персонажи/Классическое фентези/Варвар-войн.md` станет `Персонажи\Классическое фентези\Варвар-войн.docx`.
- Заголовок документа — строка с `#`. Разделы — `##`.
- Пункты списка — строки с `-` в начале.
- Жирный текст — двойными звёздочками: `**Название**`.

## Как обновить документы

```
node game-lab/tools/md2docx.mjs sync "C:\Users\InsaneHoo8\Desktop\Лайтовая настолка"
```

Команда собирает все docx заново. Пропускает файлы, начинающиеся с подчёркивания, и этот README.

## Что генерируется само

Три документа не правятся руками — они пересобираются из данных игры:

- `Персонажи/Персонажи — сводка.md` — все двенадцать с числами и замерами.
- `Персонажи/Персонажи по классам.md` — классы и доли побед.
- `Игровой процесс/Способности — пул.md` — все способности с ценами.

Их пересобирает `node game-lab/tools/gen-docs.mjs 1200`, где 1200 — число партий для замера. После этого запускается команда сборки docx выше.

## Обратный перевод

Если документ пришёл от вас в docx и его нужно внести сюда:

```
node game-lab/tools/migrate-docs.mjs "C:\Users\InsaneHoo8\Desktop\Лайтовая настолка"
```

Скрипт переводит все docx в markdown и пропускает резервные копии с «до правки» в названии.

## Промты для нейронки

Отдельная папка с тремя самодостаточными документами: артефакты, персонажи со способностями, правила и механики. Они собираются из данных игры:

```
node game-lab/tools/gen-prompt-docs.mjs
node game-lab/tools/md2docx.mjs sync "C:\Users\InsaneHoo8\Desktop\Лайтовая настолка"
```

После правки способностей или артефактов достаточно повторить эти две команды, и документы обновятся сами.
