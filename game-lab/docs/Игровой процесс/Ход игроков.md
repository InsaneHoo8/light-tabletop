# Ход игрока

Во время своего хода игрок выполняет ровно одно действие. После действия ход переходит следующему живому игроку, выбывшие пропускаются.

## Действия

- **Атака** — удар по соседу слева или справа. Через стол не бьют. Урон указан в карточке персонажа.
- **Взять артефакт** — верхняя карта из колоды артефактов уходит в руку.
- **Применить артефакт** — своя карта бесплатна, чужая стоит менталки по своей цене.
- **Применить способность** — карта из руки уходит в сброс.
- **Обменять артефакт** — на энергию или на возврат сброшенной способности.
- **Пропустить ход** — игрок отказывается от действия.

## Обмен артефакта

Обмен не тратит ход: игрок сбрасывает карту и сразу делает основное действие.

При обмене выбирают одно из двух: энергию в размере обменного значения карты или возврат одной сброшенной способности. Взять способность можно только при свободном месте в руке.

Возврат идёт по порядку. Сначала берут из свежего пула способностей. Когда пул кончился, берут верхнюю карту старого сброса. Всё, что сыграно после этого, уходит в новый сброс, и оттуда брать нельзя.

## Три шкалы

- **Здоровье** — ноль означает выбывание.
- **Менталка** — на артефакты чужих миров.
- **Энергия** — на способности.

Каждый ресурс упирается в свой максимум, сверх него не поднимается.

## Способности

У каждого персонажа личный пул из 8 способностей. Перед партией игрок собирает из него руку по лимиту из карточки. Применённая карта уходит в сброс.

## Щиты

В начале игры у всех ноль щита. Щит дают только карты и артефакты, сам он не восстанавливается.

Щит держится, пока его не разрушат. Щиты не стакаются: у персонажа одна активная карта щита, и пока щит держится, новую карту щита ставить нельзя. Исключение — Хейл, он складывает две карты. Потолок щита у каждого свой и записан в карточке.

Когда щит пробит до нуля, его карта уходит в сброс. Пробивающий урон щит не тратит.

## Реакции

Реакция играется вне очереди, в чужой ход, по условию. Она не тратит действие и срабатывает сама, если карта в руке и хватает энергии.

## Пассивки

У каждого персонажа есть постоянный эффект, который работает без розыгрыша карты. Пассивка записана в карточке персонажа.

## Победа

Побеждает последний живой. Если все выбыли одновременно, партия считается ничьей.
