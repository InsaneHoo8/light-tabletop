# Лайтовая настолка — «Война за Сосиску»

Настольная игра на четырёх игроков: двенадцать персонажей по восемь способностей, двадцать четыре артефакта по шесть на каждый из четырёх миров. Здесь лежит движок правил, бот, который играет вместо людей, инструменты сборки документов и все замеры баланса.

## Что где лежит

**`game-lab/arena/cards.js`** — все числа игры. Персонажи: здоровье, урон обычной атаки, менталка, энергия, лимит руки, ёмкость щита, текст пассивки и восемь способностей. Артефакты: цена, обменное значение, эффект.

**`game-lab/arena/engine.js`** — правила и бот. Партия, действия, урон, щиты, реакции, пассивки, оценки бота.

**`game-lab/arena/game-data.js`** — прослойка, через которую движок получает данные.

**`game-lab/patches.json`** — реестр патчей и номер текущего.

**`game-lab/arena/otchet-balansa.md`** — журнал: что менялось и какие замеры это показали.

**`game-lab/docs`** — исходники всех документов в markdown. Из них собираются файлы Word.

**`game-lab/tools`** — генераторы документов, таблиц и отчётов.

**`game-lab/sim-data`** — машинные слепки прогонов в JSON.

**`game-lab/demo`** — браузерная демонстрация игры.

## Как проверить движок

```
node game-lab/arena/tools/self-check.mjs
```

Должно быть «Все проверки пройдены».

## Как запустить симуляцию

```
node game-lab/tools/sim-report.mjs 1500 4 "C:\Users\InsaneHoo8\Desktop\Лайтовая настолка"
```

Отчёт ляжет в `game-lab/docs/Симуляция игр ботяр/Патч <версия>`, документ Word — в папку игры, слепок — в `game-lab/sim-data`.

По умолчанию каждый бот в каждой партии заново выбирает стиль: агрессивный, пассивный или обычный.

## Режимы ботов

Задаются переменными окружения перед запуском:

- `AGGRO=1` — все агрессивные
- `CAUTION=1` — все осторожные
- `MIXED=1` — двое агрессивных, двое осторожных
- `STYLES=aggro,caution,normal,hoarder` — стили по местам
- `PRIORITY=1` — строгий порядок действий
- `PREFER_EXTRA=1`, `PREFER_SHIELD=1` — приоритет картам с дополнительным действием или щитом
- `COUNTERS=1` — бот учитывает чужие артефакты
- `NO_ART_LIMIT=1` — снять ограничение руки артефактов
- `FREE_ART=1` — все артефакты бесплатны
- `COMBO=1` — поведение связки «жертвенный алтарь плюс нейростимулятор»

Полный справочник технических правил — `game-lab/docs/Промты для нейронки/Технические правила работы.md`.

## Как собрать документы

```
node game-lab/tools/md2docx.mjs sync "C:\Users\InsaneHoo8\Desktop\Лайтовая настолка"
```

Документы собираются из markdown, числа в тексте пишутся словами, шрифт Times New Roman.

## Требования

Node.js версии 24 или новее. Больше ничего: сборка на чистом JavaScript, без зависимостей.

## Что лежит в репозитории, а что нет

В git попадают код, данные и исходники документов: `game-lab/arena`, `game-lab/tools`, `game-lab/docs`, `game-lab/demo`, реестр патчей и журнал баланса.

**Не попадают** результаты прогонов — они воспроизводятся командой: `game-lab/sim-data`, отчёты в `game-lab/docs/Симуляция игр ботяр`, архивы резервных копий. Документы Word тоже вне репозитория: они собираются из markdown.

Разовые скрипты правок, которыми вносились изменения в карточки и правила, лежат в `game-lab/tools/archive`. Рабочие инструменты — в `game-lab/tools`.

## Публикация

Одна команда — проверка движка, обновление истории версий, коммит, тег и отправка на GitHub:

```
node game-lab/tools/publish.mjs "Люся: охота лечит по единице за цель" 0.0.6
```

Второй аргумент необязателен: если указан, ставится тег вида `v0.0.6`.

История версий собирается из `game-lab/patches.json` в `CHANGELOG.md` командой `node game-lab/tools/make-changelog.mjs`.
